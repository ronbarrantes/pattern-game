# Mission: Build an ATtiny85 pattern game

## Why

Build a playable, battery-powered pattern game while learning enough C and electronics to explain, test, and debug each part without relying on copied solutions.

## Success looks like

- Explain how `DDRB`, `PORTB`, and `PINB` control each input and output state.
- Combine the working button and LED tests with the pattern-game logic on the ATtiny85.
- Choose LED resistors and a coin-cell power setup using voltage and current calculations.
- Diagnose hardware and firmware problems with measurements, small tests, and register-state tracing.

## Constraints

- Use the ATtiny85 and the parts already chosen for this project.
- Keep the work student-led. Use explanations, guiding questions, and small examples instead of complete assignment solutions.
- Test one hardware behavior at a time before combining it with the game.

## Out of scope

- C features and electronics theory that do not help build or debug this game yet.
